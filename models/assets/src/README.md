# AI-Based Student Performance Analysis System

## Project Overview

The AI-Based Student Performance Analysis System is a
Python-based application designed to analyze student
academic performance using Artificial Intelligence,
Machine Learning and Natural Language Processing.

The system provides an interactive dashboard to monitor
student marks, attendance, academic performance and
student feedback.

## Features

- Interactive Student Performance Dashboard
- Student Count Visualization
- Subject-wise Examination Results
- Best Performing Students
- Attendance Analysis
- Student Profile Cards
- Machine Learning-Based Performance Risk Prediction
- NLP-Based Student Feedback Sentiment Analysis
- AI-Based Student Insights and Recommendations
- Downloadable Student Performance Report

## Technologies Used

- Python
- Streamlit
- Pandas
- Plotly
- Scikit-learn
- Joblib
- TextBlob
- Natural Language Processing
